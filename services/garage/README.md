# Garage

[Garage](https://garagehq.deuxfleurs.fr) is a self-hostable, S3-compatbile object storage service. We need it to share
files between the `web` and `worker` services.

Currently, [Render's official object storage](https://render.com/object-storage) offering is in early access. This is a
stop-gap solution until it's make generally available, or we are given access.
